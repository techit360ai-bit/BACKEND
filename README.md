## 🛠 Installation Guide

Follow these steps to get your local environment up and running.

### 🪟 For Windows (PowerShell)
```powershell
# Clone the repository
git clone [url]

# Navigate to the project
cd "TECH IT"

# Install Backend dependencies
cd backend
npm install
cd ..

# Install Frontend dependencies
cd frontend
npm install
cd ..

# Launch VS Code
code .
```

### For Mac
```bash
# Clone the repository
git clone [url]

# Navigate to the project
cd "TECH IT"

# Install dependencies using shorthand
cd backend && npm install && cd ..
cd frontend && npm install && cd ..

# Launch VS Code
code .
```

## 🐙 GitHub Workflow & Branching
[!IMPORTANT] Pushing directly to the main branch is strictly prohibited. Only the Project Manager (PM) has merge authority.

Please create a new branch for every task using the Conventional Commits categories:

```
feature/ ,New feature or functionality
fix/ ,Bug fixes
docs/ ,Documentation changes
style/ ,Code formatting (no logic changes)
refactor/ ,Code restructuring
perf/ ,Performance improvements
test/ ,Adding or updating tests
chore/ ,"Maintenance, dependencies, etc."
release/ ,Preparing a new release
hotfix/ ,Urgent production fixes
```

```powershell
Example: 

git checkout -b feature/user-auth-endpoint
```
Note : pre-push already made to restrict certain breaking of Conventional Commits categories
